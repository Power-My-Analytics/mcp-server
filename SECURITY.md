# Security

## Reporting a vulnerability

If you believe you have found a security issue in the Power My Analytics MCP
server or platform, please email **contactus@powermyanalytics.com** with the
subject line "Security report" rather than opening a public issue.

Please include a description of the issue, steps to reproduce it, and any
relevant URLs or request details. We will acknowledge your report and keep you
updated as we investigate.

## Our security practices

- Power My Analytics is SOC 2 Type II and ISO 27001 certified.
- Data is encrypted in transit and at rest.
- The MCP server uses OAuth 2.1 sign-in. No API keys are shared with AI assistants.

More information: https://www.powermyanalytics.com/security/
